# Dr. P. Ramesh — Multi-page Academic Portfolio

## Pages
- Home
- Education
- Experience
- Research
- Publications
- Projects
- Activities
- Presentations
- Professional Development
- Contact

## Run locally
Open `index.html` directly in a browser, or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Assets
The `assets/` folder contains the supplied academic profile images. Replace them with a preferred professional portrait if desired.

## Deployment
The site is static HTML/CSS/JS and can be deployed to GitHub Pages, Netlify, Vercel, or any standard web server.
